Frontend Architecture

Views (Routes)

  • / — Dashboard — KPI cards, revenue chart, order summary
  • /inventory — Inventory — stock levels, low-stock alerts
  • /orders — Orders — table with status badges, detail modal
  • /spending — Finance — spending summary, category breakdown
  • /demand — Demand — forecast table with trend indicators
  • /reports — Reports — quarterly & monthly trend data

Composables (Singletons)

  • useFilters — Global filter state. Refs live at module scope, shared across all consumers.
  • useAuth — Mock user (always authenticated). Language-aware name/title via useI18n.
  • useI18n — Custom i18n. Locale persisted in localStorage. EN/JA. Currency follows locale (USD / JPY at fixed ×150 rate).

Shared Components

  • FilterBar — Always visible below top nav
  • ProfileMenu + ProfileDetailsModal — User profile drawer
  • TasksModal — Task CRUD (persisted to backend)
  • BacklogDetailModal, InventoryDetailModal, etc. — Detail overlays

Key Constraints & Gotchas

No Persistence

All data is loaded from JSON at server startup and held in Python module-level lists. Restarting the server resets everything (except Tasks which are mutated in-memory).

Filter Scope

Inventory endpoint ignores month — stock has no time dimension. Demand and Backlog accept no filters at all. Only Orders and Dashboard support all 4 filters.

Currency / i18n

All stored values are USD. JPY is computed client-side at a fixed ×150 rate via currency.js. Switching locale also switches user name, job title, and task descriptions.
